# case-rim-reverse: фланец форсунки развёрнут на 180°

Копия `case-rim`. Отличие одно: фланец лансета развёрнут на 180° вокруг оси лансета, поэтому корпус форсунки и диск смотрят **навстречу потоку газа**:

| | `case-rim` | `case-rim-reverse` |
|---|---|---|
| Лансет | x = 2.245 м | без изменений |
| Диск ⌀65 | x = 2.406–2.414 м, за лансетом | **x = 2.076–2.084 м, перед лансетом** |
| Масло | сходит с кромки диска вниз по потоку | сходит с кромки диска; направление форсунки (-1 0 0) |

**Что изменено:**
- геометрия: `constant/geometry/nozzle.stl` — зеркальное отражение форсунки относительно оси лансета (`geometry/build_geometry.py`, `export_cfd_nozzle(reverse=True)`);
- впрыск: `constant/cloudProperties`, `position (2.080 0 0)`, `direction (-1 0 0)`.

Всё остальное (газ, вход с закруткой, масло, дробление) — как в `case-rim`.

**Запуск:**

```bash
python ../mesh/make_blockmesh.py 0.8 --zone rim-reverse
```

```bash
./Allrun && ./Allrun.spray && ./deposition
```

На картинке `deposition.png` пунктир «диск» стоит на старом месте (2.41 м); диск здесь на 2.08 м.
