# case-rim: масло сходит с кромки диска и дробится газом

Та же укороченная область, что в `case-throat` (x = 1.75 м … диффузор + 0.6 м). Разница — в том, как задано масло.

| | `case-throat` | `case-rim` |
|---|---|---|
| Где рождаются капли | кольцо r = 50–150 мм за диском | **кромка диска**, r = 33–35 мм, середина толщины диска |
| Направление | 65–85° от оси | 80–95°: плёнка сходит с плоского диска почти радиально |
| Размер на старте | уже мелкие, d32 ≈ 88 мкм (задан по корреляциям) | **крупные первичные капли ~1 мм**, как от распада плёнки толщиной ~1.5 мм |
| Дальше | размер не меняется | **газ дробит капли** (модель Reitz–Diwakar: «мешок» и срыв с поверхности), конечный размер — результат расчёта |
| Облако | `thermoCloud` | `sprayCloud` |
| Газ | однокомпонентный (`fluid`) | смесь «псевдогаз + пар масла» (`multicomponentFluid`); доля пара всегда 0, испарения нет |
| Масло | твёрдое тело с постоянными свойствами | жидкость `oil`: ρ 1150, μ 46 мПа·с, σ 0.03 Н/м, cp 1950 (`constant/physicalProperties`) |

Удар струи из трубки о диск и растекание по нему **не моделируются**: масло появляется сразу на кромке. Это ближе к реальности, чем рождение за диском, но плёнка на диске по-прежнему не считается.

## Запуск

```bash
python ../mesh/make_blockmesh.py 0.8 --zone rim
```

```bash
./Allrun && ./Allrun.spray && ./deposition
```

Скрипты те же, что в `case-throat`: `stop`, `Allcontinue`, `plot`, `mapInlet`.

В логе масла после каждого пересчёта облака есть строка `D10, D32, Dmax (mu)`. Она показывает размер капель, которые ещё летят на момент записи. В стационарном облаке к концу пересчёта все капли уже ушли, поэтому там часто нули. Реальные размеры при ударе о стенку и на выходе — в `deposition_summary.txt`.

## Что можно менять

Всё в `constant/cloudProperties`, блок `diskRim`:

| Параметр | Что меняет |
|---|---|
| `thetaInner`, `thetaOuter` | угол схода плёнки (90° — строго радиально, больше 90° — назад) |
| `Umag` | скорость схода |
| `sizeDistribution` (`d`, `min`, `max`) | размер первичных капель |

Коэффициенты дробления — блок `ReitzDiwakarCoeffs`.

## Результат проверочного прогона

Сетка 0.8, 4 ядра. Газ — 600 итераций, масло — 600 итераций.

**Расчёт:**
- 0 предупреждений о сетке;
- пересчёт облака занимает несколько секунд.

**Капли:**
- первичные ~1 мм дробятся газом до **≈ 90–100 мкм**; это совпадает с оценкой по корреляциям, d32 ≈ 88;
- к моменту удара о стенку капли прогреваются до ~365 °C.

**Куда уходит масло:**
- **~91 % — на стенку**: основная масса в диффузоре, x ≥ 2.85 м, равномерно по окружности;
- **на выходе горловины** (x 2.55–2.75 м) — **редкие попадания** на горячую стенку, оценка T плёнки > 380 °C (красное на карте);
- ~9 % — с газом через выход.
