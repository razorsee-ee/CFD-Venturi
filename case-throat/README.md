# Укороченная модель: форсунка + конфузор + горловина

Для быстрых экспериментов с форсункой на более мелкой сетке.

**Область:** x = 1.75 м (середина конфузора, 0.5 м до лансета) … 0.6 м в диффузор за горловиной, плюс прямая труба 0.3 м под выходную границу.

**Сетка:** тот же генератор, но шаг вдоль оси 4 мм у форсунки и в горловине (в полном кейсе 6 мм).

| Масштаб | Ячеек (с вырезом форсунки) | Время газа на 8 ядрах |
|---|---|---|
| 0.8 | ~0.52 млн | ~20 мин |
| 1.0 | ~1.0 млн | ~40 мин |

## Вход

Условия на входе берутся из **газового решения полного кейса** в сечении x = 1.75 м.

| Величина | Как задаётся |
|---|---|
| Скорость | `swirlFlowRateInletVelocity`: **точный массовый расход 21.11 кг/с** и окружная скорость W(r) — среднее по окружности из полного решения, файл `constant/inletSwirl`. Осевая скорость равномерная. В полном решении она на этом сечении неравномерна на ±8 %, до лансета ещё 0.5 м. |
| T, k, ω | переносятся как есть (`timeVaryingMappedFixedValue`). Эталон лежит в `constant/inletProfile`, `Allrun` копирует его в `constant/boundaryData/inlet`. |

Перенести саму скорость напрямую нельзя. Масло поднимает давление на входе на ~3 кПа, плотность газа растёт, и при заданной скорости расход «уплывал» на +2 %.

- **В репозитории уже лежат готовые данные:** полный кейс, сетка 0.65, закрутка S = 0.6.
- **Если поменял полный кейс** (закрутку, расход, температуру): досчитай в нём газ (`../case/Allrun`), затем здесь:
  ```bash
  ./mapInlet
  ```
  Он снимет сечение с последней сохранённой итерации `../case` и обновит `constant/inletSwirl` и `constant/inletProfile`. Брать нужно **газовое** решение, до включения масла.

## Выход

Внутри диффузора задано среднее давление (`fixedMean`), закрученный поток выходит свободно. Капли, ушедшие через выход, улетели дальше в диффузор. В отчёте `./deposition` они помечены как `outlet`.

## Запуск

```bash
python ../mesh/make_blockmesh.py 0.8 --zone throat
```

```bash
./Allrun && ./Allrun.spray && ./deposition
```

Скрипты те же, что в `case/`: `stop`, `Allcontinue`, `plot`, `Allclean`.

## Что пробовать

Всё в `constant/cloudProperties`, блок `injectionModels/deflectorDisk`:

| Параметр | Что меняет |
|---|---|
| `position` | x кольца рождения капель (диск: передняя грань x = 2.414 м) |
| `dInner`, `dOuter` | радиус, на котором плёнка распадается на капли |
| `thetaInner`, `thetaOuter` | угол вылета от оси (90° — строго радиально) |
| `Umag` | скорость вылета |
| `sizeDistribution` (`d`, `min`, `max`) | размер капель; расчёт по корреляциям: `python ../design/droplet_size.py` |

Положение и размер самого диска и лансета задаются в `geometry/params.py`. После правки:
1. `python geometry/build_geometry.py` (нужен cadquery) → новый `nozzle.stl`;
2. скопировать его из `case/constant/geometry/` в `case-throat/constant/geometry/`.

## Замечания

- `checkMesh` сообщает о ~20–50 «сильно скошенных» гранях на поверхности лансета (`Failed 1 mesh checks`). Ячейки там вытянуты: вдоль оси 4 мм, поперёк ~10 мм. На устойчивость расчёта это не влияет.
- Масло: ρ 1150 кг/м³, cp 1950, 40 сСт при 100 °C. Капли: Розин–Раммлер d = 130 мкм (d32 ≈ 88 мкм) — см. `design/droplet_size.py`.

## Результат проверочного прогона

Сетка 0.8 (~0.52 млн ячеек), 4 ядра. Масло с новыми свойствами: ρ 1150, d32 88 мкм. Закрутка S = 0.6 — вход снят с полного кейса.

**Газ:**
- сходится устойчиво, расход 21.110 кг/с;
- ~0.95 с на итерацию на 4 ядрах.

**С маслом:**
- перепад давления x = 1.75 м → выход ≈ 3.0 кПа;
- T газа на выходе области ≈ 391 °C (дальше по диффузору газ остывает ещё);
- ограничитель давления не срабатывает, застрявших капель нет.

**Куда уходит масло:**
- ~71 % на стенку, ~29 % улетает дальше в диффузор;
- капли прилетают на стенку с T ≈ 340 °C (от 200 до 440 °C), d ≈ 130 мкм.

**Где масло попадает на стенку:**

| Участок | x, м | Что происходит |
|---|---|---|
| Горловина | 2.55–2.65 | масла мало и оно ложится пятнами → тонкая горячая плёнка 340–420 °C — **зона риска кокса в горловине** |
| Начало диффузора | 2.65–2.75 | масла много → плёнка 250–300 °C |
| Дальше по диффузору | после 2.75 | плёнка 300–380 °C |

Картинка: `docs/deposition_throat_zoom.png`.

## Брызги с кромки диска (`splashCloud`) — по умолчанию выключены

Чтобы включить:
- в `constant/fvModels.spray` (и в `constant/fvModels`, если масло уже идёт) поставь `clouds (cloud splashCloud);`;
- в `constant/cloudProperties` поставь `massFlowRate 8.0`.

Выключены они потому, что мелкие капли в вихре за диском охлаждают газ до ~100–200 °C (тёмное пятно на поле T). Это следствие допущения «10 % брызг», а не результат. Кроме того, на Windows-сетке они сильно замедляли расчёт.

**Что задано:** 10 % масла (0.89 кг/с) мелкими каплями, d32 ≈ 30 мкм, 15 м/с, от кромки диска во все стороны, вплоть до 150° назад, против потока. Основной впрыск — 90 % (8.0 кг/с).

**Результат** (тот же прогон, сетка 0.8):
- **100 % брызг уходят с газом через выход** в диффузор;
- на стенку, лансет или диск не попало ничего: даже вылетевшие назад капли газ разворачивает за несколько сантиметров;
- при подлёте к выходу брызги нагреты до ~350 °C, d ≈ 40 мкм.

**Вывод для этой модели:** обратного заброса масла на форсунку и в конфузор нет. Отложения в горловине дают крупные капли основного факела (~130 мкм), а не брызги.

`./deposition` анализирует оба облака. Если капли облака на стенку не попадают, карта для него не рисуется.

## ParaView: где масло садится на стенку

`./deposition` пишет `VTK/walls_oil.vtk` — поверхность стенок с полями, посчитанными из ударов капель:

| Поле | Что это |
|---|---|
| `oil_flux_kg_m2s` | поток масла на стенку, кг/(м²·с) |
| `T_film_C` | оценка температуры плёнки, °C |
| `T_impact_C` | средняя температура капель при ударе, °C |
| `coking_risk_0dry_1low_2mod_3high` | зона риска: 0 — сухо, 1 — низкий, 2 — умеренный, 3 — высокий |

ParaView: **File → Open** → `VTK/walls_oil.vtk` → **Apply** → раскраска по нужному полю.

Поля OpenFOAM вида `cloud:...` на Windows в ParaView не видны: двоеточие нельзя использовать в именах файлов.
