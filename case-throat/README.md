# Укороченная модель: форсунка + конфузор + горловина

Для быстрых экспериментов с форсункой на более мелкой сетке.

**Область:** x = 1.75 м (середина конфузора, 0.5 м до лансета) … 0.6 м в диффузор за горловиной, плюс прямая труба 0.3 м под выходную границу.

**Сетка:** тот же генератор, но шаг вдоль оси 4 мм у форсунки и в горловине (в полном кейсе 6 мм).

| Масштаб | Ячеек (с вырезом форсунки) | Время газа на 8 ядрах |
|---|---|---|
| 0.8 | ~0.52 млн | ~20 мин |
| 1.0 | ~1.0 млн | ~40 мин |

## Вход

Профили U, T, k, ω на входе (закрутка, турбулентность) берутся из **газового решения полного кейса** в сечении x = 1.75 м. Их переносит граничное условие `timeVaryingMappedFixedValue`. Эталонные данные лежат в `constant/inletProfile`. При каждом запуске `Allrun` копирует их в `constant/boundaryData/inlet` и масштабирует скорость так, чтобы расход был ровно 21.11 кг/с: при переносе профиля на другую сетку он смещается на 1–2 %.

- **В репозитории уже лежат готовые данные:** полный кейс, сетка 0.65, закрутка S = 0.6.
- **Если поменял полный кейс** (закрутку, расход, температуру): досчитай в нём газ (`../case/Allrun`), затем здесь:
  ```bash
  ./mapInlet
  ```
  Он снимет сечение с последней сохранённой итерации `../case`. Брать нужно **газовое** решение, до включения масла.

## Выход

Внутри диффузора задано среднее давление (`fixedMean`), закрученный поток выходит свободно. Капли, ушедшие через выход, улетели дальше в диффузор. В отчёте `./deposition` они помечены как `outlet`.

## Запуск

```bash
python ../mesh/make_blockmesh.py 0.8 --zone throat
```

```bash
./Allrun && ./Allrun.spray && ./deposition
```

Скрипты те же, что в `case/`: `stop`, `Allcontinue`, `plot`, `Allclean`.

## Что пробовать

Всё в `constant/cloudProperties`, блок `injectionModels/deflectorDisk`:

| Параметр | Что меняет |
|---|---|
| `position` | x кольца рождения капель (диск: передняя грань x = 2.414 м) |
| `dInner`, `dOuter` | радиус, на котором плёнка распадается на капли |
| `thetaInner`, `thetaOuter` | угол вылета от оси (90° — строго радиально) |
| `Umag` | скорость вылета |
| `sizeDistribution` (`d`, `min`, `max`) | размер капель; расчёт по корреляциям: `python ../design/droplet_size.py` |

Положение и размер самого диска и лансета задаются в `geometry/params.py`. После правки:
1. `python geometry/build_geometry.py` (нужен cadquery) → новый `nozzle.stl`;
2. скопировать его из `case/constant/geometry/` в `case-throat/constant/geometry/`.

## Замечания

- `checkMesh` сообщает о ~20–50 «сильно скошенных» гранях на поверхности лансета (`Failed 1 mesh checks`). Ячейки там вытянуты: вдоль оси 4 мм, поперёк ~10 мм. На устойчивость расчёта это не влияет.
- Масло: ρ 1150 кг/м³, cp 1950, 40 сСт при 100 °C. Капли: Розин–Раммлер d = 130 мкм (d32 ≈ 88 мкм) — см. `design/droplet_size.py`.
