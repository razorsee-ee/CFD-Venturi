# Кейс OpenFOAM-12: скруббер Вентури, горячий пиролизный газ и масляный спрей

Проверено на OpenFOAM-12 (Foundation, сборка Linux): грубая сетка (масштаб 0.5, ~150 тыс. ячеек), газ и масло.
У тебя тот же OpenFOAM-12 в blueCFD-Core.

## Запуск

Сетка, масштаб 0.65 (~290 тыс. ячеек):

```bash
python ../mesh/make_blockmesh.py 0.65
```

Этап 1: сетка и газ (стационарно, сходится примерно за 900–1000 итераций):

```bash
./Allrun
```

Этап 2: масло 32 т/ч, ещё 1500 итераций от газового решения:

```bash
./Allrun.spray
```

Окно с графиками открывается само (`./plot`). Картинка дублируется в `convergence.png`.

| Действие | Команда |
|---|---|
| Остановить с записью | `foamDictionary system/controlDict -entry stopAt -set writeNow` |
| Продолжить остановленный расчёт | `./Allcontinue` |
| Очистить всё, кроме настроек | `./Allclean` |
| Собрать результат для ParaView | `reconstructPar -latestTime`, затем `paraFoam -builtin` |

## Что считается

- **Газ.** Псевдогаз `pyroGas`: M = 67.4, cp = 2835, μ = 1.82·10⁻⁵. Расход 21.11 кг/с, 470 °C, k-ω SST, стационарно, схемы первого порядка.
- **Масло.** Инертные капли с постоянными свойствами: ρ 920, cp 2100.
  - Без испарения, конденсации и дробления.
  - Впрыск кольцом с кромки диска ⌀65: 65–85° от оси, 25 м/с, Розин–Раммлер d = 110 мкм.
- **Капля, задевшая стенку, лансет или выход, удаляется из расчёта.** В логе печатается, сколько масла ушло куда:
  ```bash
  grep -A16 "^Cloud: cloud" log.foamRun.spray | tail -17
  ```
  Плёнка масла на стенке не моделируется.

## Важные настройки (не трогать без нужды)

- **`system/fvSolution`: `relaxationFactors/fields/rho 0.05`.** При значении 1 стационарный сжимаемый расчёт разваливается с первой итерации: давление уходит в минус.
- **`system/fvSchemes`: схемы `upwind` (первого порядка).** Со вторым порядком решение устойчиво, но перепад давления «гуляет» от 0.2 до 1 кПа. Причина — нестационарный отрыв в диффузоре.

## Что получилось на тестовой сетке

**Газ:**
- сходится за 941 итерацию;
- расход на выходе 21.11 кг/с;
- перепад давления вход–выход около 0.7 кПа;
- в диффузоре (полный угол 11°) поток отрывается со стороны лансета, у верхней стенки есть обратный ток.

**Масло:**
- около 88 % массы долетает до стенки конфузора;
- около 11 % попадает обратно на диск и лансет;
- на выход уходит меньше 1 %.

  Капля ~100 мкм на 25 м/с пролетает поперёк потока около 0.7 м, а до стенки ~0.3 м. Для дисковой форсунки это реалистично: в настоящем аппарате масло со стенки срывается газом в горловине уже плёнкой. Эффект охлаждения в такой модели будет занижен.
