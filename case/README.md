# Кейс OpenFOAM-12: скруббер Вентури, горячий пиролизный газ и масляный спрей

Проверено на OpenFOAM-12 (Foundation, сборка Linux): грубая сетка (масштаб 0.5, ~150 тыс. ячеек), газ и масло.
У тебя тот же OpenFOAM-12 в blueCFD-Core.

## Запуск

Сетка, масштаб 0.65 (~290 тыс. ячеек):

```bash
python ../mesh/make_blockmesh.py 0.65
```

Этап 1: сетка и газ (стационарно, сходится примерно за 900–1000 итераций):

```bash
./Allrun
```

Этап 2: масло 32 т/ч, ещё 1500 итераций от газового решения:

```bash
./Allrun.spray
```

Окно с графиками открывается само (`./plot`). Картинка дублируется в `convergence.png`.

Скрипты меняют в `system/` только отдельные значения: `endTime`, `stopAt`, `residualControl`. После `./Allclean` файлы снова совпадают с версией в git, так что `git pull` не конфликтует.

| Действие | Команда |
|---|---|
| Остановить с записью (из второго окна терминала) | `./stop` |
| Продолжить остановленный расчёт | `./Allcontinue` |
| Продолжить и досчитать ещё N итераций | `./Allcontinue 1000` |
| Очистить всё, кроме настроек | `./Allclean` |
| Собрать результат для ParaView | `reconstructPar -latestTime`, затем `paraFoam -builtin` |

## Что считается

- **Газ.** Псевдогаз `pyroGas`: M = 67.4, cp = 2835, μ = 1.82·10⁻⁵. Расход 21.11 кг/с, 470 °C, k-ω SST, стационарно.
- **Закрутка на входе** (газ идёт из вихревой трубы циклона через колено):
  - вращение как твёрдого тела, ω = 84 рад/с (окружная скорость 37 м/с у стенки), число закрутки S = 0.6 — «сильная»;
  - турбулентность 15 %;
  - задаётся в `0.orig/U` (`omega`); `omega 0` — без закрутки.
- **Масло.** Инертные капли с постоянными свойствами: ρ 1150 (1.2 кг/л в холодном), cp 1950, 40 сСт при 100 °C.
  - Без испарения, конденсации и дробления.
  - Капли рождаются на кольце r = 50–150 мм за диском ⌀65: 65–85° от оси, 25 м/с, Розин–Раммлер d = 130 мкм (d32 ≈ 88 мкм, `design/droplet_size.py`).
- **Капля, задевшая стенку, лансет или выход, удаляется из расчёта.** В логе печатается, сколько масла ушло куда:
  ```bash
  grep -A16 "^Cloud: cloud" log.foamRun.spray | tail -17
  ```
  Плёнка масла на стенке не моделируется.

## Важные настройки (не трогать без нужды)

- **`system/fvSolution`: `consistent yes` (SIMPLEC) и `p 1`.** С обычным SIMPLE (`consistent no`, `p 0.3`) закрученный поток на сетке 0.65 раскачивался: давление на входе скакало ±50 кПа и упиралось в ограничитель.
- **`system/fvSolution`: `relaxationFactors/fields/rho 0.05`.** При значении 1 стационарный сжимаемый расчёт разваливается с первой итерации: давление уходит в минус.
- **`system/fvSchemes`: скорость — второй порядок (`linearUpwindV`), остальное — первый.** Схема первого порядка «съедает» ~30 % закрутки к горловине. С закруткой отрыва в диффузоре нет, и второй порядок устойчив.
  - Невязка по p выходит на полку ~1e-3, поэтому газовый этап идёт до 2000 итераций. Смотри, чтобы перепад давления и температура на графике перестали меняться.
  - Если убрать закрутку (`omega 0`), верни `upwind` для `div(phi,U)`: без закрутки диффузор отрывается, и со вторым порядком перепад «гуляет».

## Что получилось на тестовой сетке

(Результаты с маслом ниже посчитаны ещё со старыми свойствами: ρ 920, d = 110 мкм.)

**Газ:**
- сходится за 941 итерацию;
- расход на выходе 21.11 кг/с;
- перепад давления вход–выход около 0.7 кПа;
- в диффузоре (полный угол 11°) поток отрывается со стороны лансета, у верхней стенки есть обратный ток.

**Масло, сравнение без закрутки и с сильной закруткой** (1000 итераций после включения):

| | Без закрутки | Закрутка S = 0.6 |
|---|---|---|
| Перепад давления (только газ) | 0.71 кПа | 0.32 кПа (нет отрыва в диффузоре) |
| Перепад давления (с маслом) | 1.64 кПа | 2.41 кПа |
| T газа на выходе | 376 °C | 380 °C (предел 382) |
| Масло на стенки | 30 % | **90 %** |
| из него в горловине и диффузоре | ~4 % | **83 %** |
| Масло уходит с газом | 70 % | 10 % |
| Капли в момент удара | ~400 °C | ~380–400 °C |

С закруткой газ работает как центрифуга: прогретые капли отбрасываются на стенку сразу за горловиной. Максимум осаждения — первые 1–1.5 м диффузора, равномерно по окружности. Картинки: `docs/deposition_test_coarse.png` (без закрутки), `docs/deposition_swirl_coarse.png` (с закруткой).

## Куда летит масло и где возможен кокс

После `./Allrun.spray`, или после `./stop` на этапе с маслом:

```bash
./deposition
```

Скрипт собирает все удары капель за последние 4 вычисления облака и пишет три файла:

| Файл | Что внутри |
|---|---|
| `deposition.png` | 1) поток масла на стенку на развёртке обечайки, вдоль оси × по углу; 2) оценка температуры масла на стенке; 3) доля осевшего масла вдоль оси; 4) температура капель в момент удара |
| `deposition_summary.txt` | сколько масла ушло на обечайку, на диск/лансет и на выход; смоченная площадь; распределение по зонам риска |
| `deposition_bins.csv` | то же по ячейкам 50 мм × 15°, для Excel |

**Как оценивается температура масла на стенке.** Для каждой ячейки развёртки составлен баланс: свежее масло прилетает с температурой капель, а газ греет его через теплоотдачу:

    m''·cp_oil·(T_film − T_капли) = h·(T_газа − T_film)

Теплоотдача `h` берётся по аналогии Кольборна из трения газа о стенку. Что из этого следует:
- **Много масла** → плёнку постоянно обновляет холодное масло → T_film ≈ температуре капель (риск мал).
- **Редкие капли** на горячую стенку (~450 °C) → тонкая перегретая плёнка → **именно там образуется кокс**.

Границы зон (<300 °C, 300–380 °C, >380 °C) — ориентир для тяжёлого масла. Реальный порог зависит от масла: коксуемости по Конрадсону, асфальтенов, времени пребывания плёнки.

**Чего модель не знает:**
- **Плёнка не течёт.** На самом деле масло со стенки конфузора газ тащит в горловину. Красные зоны сразу за мокрой полосой в реальности могут быть залиты стекающей плёнкой, а дальше по потоку плёнка истончается и греется.
- **Брызги при ударе не считаются.** We ≈ 2000, капли разбиваются, часть масла снова уходит в поток.
- **Стенка без теплопроводности.** Сталь и изоляция выравнивают температуру между мокрыми и сухими местами.

Следующий шаг для честного ответа о коксе — модель плёнки (в OpenFOAM-12 это отдельный регион `film`, связанный с облаком капель). Она даёт толщину, температуру и сухие пятна плёнки.

В ParaView:
- поле `cloud:massCollisionDensity` на `patch/walls` — поток масла на стенку, кг/(м²·с);
- траектории капель — `VTK/lagrangian/cloudTracks`.
