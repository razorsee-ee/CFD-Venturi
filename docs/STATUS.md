# Состояние проекта (памятка для продолжения работы)

Ветка: `claude/hopeful-noether-1zya1a`. Пользователь общается по-русски.

## Что это
CFD-кейс OpenFOAM-12 (Foundation) для скруббера Вентури: горячий пиролизный газ + орошение тяжёлым маслом.
Пользователь запускает у себя: Windows, blueCFD-Core 2024 (OpenFOAM-12, MS-MPI), терминал MSYS2.
Основной компьютер теперь: i7-9700, 8 физических ядер без HT, 16 ГБ. Python там из MSYS2: пакеты ставятся через `pacman`, не pip.

## Структура
- `geometry/params.py` — размеры с чертежа (внутренняя полость). `build_geometry.py` → STEP/STL (CadQuery).
- `mesh/make_blockmesh.py [scale]` — структурированная O-сетка → `case/system/blockMeshDict`. Лансет и диск вырезает snappyHexMesh.
- `case/` — кейс; скрипты:
  - `Allrun` — газ;
  - `Allrun.spray` — +1500 итераций с маслом;
  - `deposition` — анализ осаждения;
  - `stop`, `Allcontinue [N]`, `plot`, `Allclean`;
  - `bin.sh` — sed-хелперы: правят значения в system/ без конфликтов git.
- `tools/plot_convergence.py` — графики; `tools/deposition_analysis.py` — карта осаждения и оценка T плёнки.
- `design/pseudo_gas.py` — состав и свойства псевдогаза, рабочая точка.
- `docs/` — эскизы, гайд ParaView, эталонные картинки.

## Физика и допущения
- Газ: 76 т/ч, 470 °C → один псевдокомпонент `pyroGas` (M 67.4, cp 2835, μ 1.82e-5). Конденсация не моделируется.
- Вход: массовый расход 21.11 кг/с, **сильная закрутка** (газ идёт из вихревой трубы циклона через колено ~2 м до скруббера):
  - вращение как твёрдого тела, ω = 84 рад/с, S = 0.6;
  - турбулентность 15 %.
- Масло: 32 т/ч, 100 °C, облако `thermoCloud` — инертные капли, без испарения и дробления.
  - Капли рождаются на кольце r = 50–150 мм в 1 см за диском, 65–85°, 25 м/с.
  - Если впрыскивать на кромке диска, газ локально «взрывался» (U > 3000 м/с).
- Стационарная постановка, облако пересчитывается каждые 10 итераций.

## Ключевые численные настройки и почему
- `fvSolution`:
  - `rho 0.05` — без релаксации плотности расчёт расходится с первой итерации;
  - `consistent yes` (SIMPLEC), `p 1` — с SIMPLE закрученный поток на сетке 0.65 качался ±50 кПа.
- `fvSchemes`:
  - `div(phi,U)` второго порядка — upwind съедал ~30 % закрутки;
  - без закрутки (`omega 0`) вернуть upwind: отрыв в диффузоре даёт колебания.
- Облако: источники `semiImplicit 0.5`; `localInteraction` — все патчи `escape`, это даёт статистику по патчам.

## Результаты (сетка 0.65 и 0.5 совпадают)

| | Без закрутки | Закрутка S = 0.6 |
|---|---|---|
| Перепад давления, только газ | 0.71 кПа | ~0.27–0.32 кПа |
| Перепад давления, с маслом | 1.64 кПа | 2.4 кПа |
| T газа на выходе | 376 °C | 380 °C (предел 382) |
| Масло на стенки | 30 % | ~90 %, в основном первые 1–1.5 м диффузора |
| Капли в момент удара | ~400 °C | ~390 °C |

**Расхождение с практикой:** у пользователя отложения **всегда в горловине**, при любой ориентации форсунки.
Гипотезы (модель их пока не содержит):
1. Плёнка масла стекает в горловину и перегревается.
2. Конденсация тяжёлых фракций (мазут + тяжёлое масло — 2/3 массы газа) при смешении в горловине.
3. Удар пыли, сажи и смоляного тумана из циклона о мокрую стенку на входе в горловину.

## Новые данные от пользователя (ещё НЕ внесены в кейс)
- Масло: ρ ≈ 1.2 кг/л (≈1150 при 100 °C), вязкость 40 сСт при 100 °C (μ ≈ 46 мПа·с).
- Оценка капель (Нукияма–Танасава + вторичное дробление): d32 ≈ 85–90 мкм, d_max ~200 мкм.
- Внести: `rho0 1150`, `Cp0 ~1950`, Розин–Раммлер d = 130 мкм (d32 ≈ 88), max 400 мкм. Те же значения в `physicalProperties` (`oilCoeffs`).
- σ не известно, принято 0.03 Н/м.

## Тестирование у себя (облачный контейнер)
- OpenFOAM-12 собирался из исходников в `/opt/OpenFOAM-12`, окружение `source /opt/of12env.sh`.
- Для mpirun от root: `OMPI_ALLOW_RUN_AS_ROOT=1 OMPI_ALLOW_RUN_AS_ROOT_CONFIRM=1`.
- В свежем контейнере сборку нужно повторить (~2–3 ч на 4 ядрах).
- Не использовать `pkill -f` с шаблоном, который есть в собственной командной строке: убивает свою же команду.
