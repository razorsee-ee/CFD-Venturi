# ParaView для этого кейса: пошагово

Координаты модели (в метрах):

| Что | Где |
|---|---|
| Ось потока | X; газ идёт от x = 0 (вход) до x = 6.9 (выход с удлинением) |
| Ось аппарата | y = 0, z = 0 |
| Лансет | входит сверху, вдоль +Y, при x ≈ 2.25 |
| Диск форсунки | x ≈ 2.41 |
| Горловина | x = 2.525…2.773 |

## 0. Запуск

Вариант А, из терминала blueCFD:

```bash
cd $FOAM_RUN/CFD-Venturi/case
```

```bash
paraFoam -builtin
```

Команда сама откроет ParaView с этим кейсом.

Вариант Б: создать в папке `case` пустой файл `case.foam`:

```bash
touch case.foam
```

Затем запустить ParaView из меню «Пуск» и открыть файл через **File → Open**. Узнать путь к папке в Windows:

```bash
cygpath -w $PWD
```

## 1. Интерфейс

- **Pipeline Browser** (слева вверху) — дерево данных и фильтров. Глаз слева от имени включает и выключает показ.
- **Properties** (слева внизу) — настройки выбранного элемента. **После любого изменения нажимать зелёную кнопку Apply.** Без неё ничего не произойдёт: это самая частая ошибка новичков.
- **Верхние панели:**
  - выпадающий список **раскраски**: Solid Color / U / p / T;
  - список **представления**: Surface / Surface With Edges / Wireframe / Outline;
  - кнопки **времени**: ⏮ ◀ ▶ ⏭; ⏭ (Last Frame) — последняя итерация;
  - кнопки **камеры**: Reset Camera, взгляд вдоль ±X/±Y/±Z.
- **Мышь:**
  - левая — вращать;
  - средняя (колесо нажатием) — сдвигать;
  - правая или прокрутка — масштаб.

## 2. Загрузка кейса

1. Выбери в Pipeline Browser `case.foam`. В Properties проверь:
   - **Case Type.** `Reconstructed Case`, если выполнялся `reconstructPar`. `Decomposed Case`, если расчёт шёл на 8 ядрах и сборки ещё не было. Если сомневаешься, выбирай Decomposed: она работает, пока есть папки `processor*`.
   - **Mesh Regions.** Оставь `internalMesh` (объём). Для стенок и форсунки отметь `patch/walls`, `patch/nozzle`.
   - **Cell Arrays.** Отметь `U`, `p`, `T` (можно все).
2. **Apply.**
3. Нажми **⏭ Last Frame** — покажется последний сохранённый результат.

## 3. Посмотреть сетку

1. В списке представления выбери **Surface With Edges** — на поверхности видна сетка.
2. Объём закрывает форсунку. Чтобы её увидеть, сделай разрез (п. 4) или оставь в Mesh Regions только `patch/nozzle` → Apply.
3. Сетка в разрезе:
   - выбери `case.foam` → **Filters → Alphabetical → Slice** (или иконка куба с плоскостью на панели);
   - Properties: **Origin** = `2.4 0 0`, **Normal** = `0 0 1` — продольная вертикальная плоскость через ось и лансет;
   - отметь **Crinkle slice** — показывает целые ячейки, а не их срез;
   - сними **Show Plane**, чтобы не мешала рамка-манипулятор;
   - **Apply** → представление **Surface With Edges**;
   - кнопка камеры **-Z** (смотреть вдоль Z) → приблизь зону форсунки и горловины.

   Что должно быть видно:
   - сгущение ячеек к стенке;
   - мелкие ячейки вокруг лансета и диска;
   - ровная структурированная сетка в остальном объёме.

## 4. Поля скорости, давления и температуры

1. Сделай обычный **Slice** (как выше, но без Crinkle slice), Origin `2.4 0 0`, Normal `0 0 1`, **Apply**.
2. В списке раскраски выбери **U** (Magnitude), затем **p** и **T**.
3. Если цвета «застыли» в одном тоне — кнопка **Rescale to Data Range** (иконка с двумя стрелками у палитры).
4. Легенду включает кнопка **Toggle Color Legend Visibility**.
5. Сечение горловины: ещё один Slice на `case.foam` с Origin `2.65 0 0`, Normal `1 0 0`.

Что смотреть:
- **U** — разгон до ~75–80 м/с в горловине, след за диском и лансетом, нет ли срыва потока в диффузоре;
- **p** — падение в горловине и частичное восстановление в диффузоре;
- **T** — без масла должна быть почти везде 470 °C; со спреем — зона охлаждения за диском.

## 5. График вдоль оси

1. Выбери `case.foam` → **Filters → Alphabetical → Plot Over Line**.
2. Point1 = `0 0.1 0`, Point2 = `6.9 0.1 0`. Линия на 100 мм выше оси, чтобы не попасть в диск и лансет.
3. **Apply** → откроется окно с графиками.
4. Слева в списке оставь галочки только на `p` или `U_Magnitude`.

## 6. Капли (после Allrun.spray)

1. `case.foam` → Mesh Regions → отметь **lagrangian/cloud** → **Apply**.
2. В Pipeline Browser выбери этот блок. Представление **Points** или **Point Gaussian**, размер точек 2–3.
3. Раскраска: **d** — диаметр, **T** — температура капель, **U** — скорость.
4. Если много точек тормозит — **Filters → Mask Points** (показывает каждую N-ю).

## 7. Сохранить

- Картинка: **File → Save Screenshot**.
- Всю настройку (разрезы, цвета, камеру): **File → Save State** (.pvsm). В следующий раз — **File → Load State**, и всё восстановится на новых результатах.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Пустой экран после открытия | Не нажат Apply, или камера не там — Reset Camera |
| Нет полей U/p/T, только время 0 | Нажать Last Frame; проверить Case Type (Decomposed/Reconstructed) |
| Всё одного цвета | Rescale to Data Range |
| Форсунка не видна | Она внутри объёма: сделай Slice или выключи internalMesh |
| Медленно | Выключи internalMesh, работай со срезами |
