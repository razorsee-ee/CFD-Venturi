# nozzle-vof-3d: струя масла → диск → плёнка → разрыв (3D VOF)

Продолжение `nozzle-vof`. В 2D плёнка не может порваться на нити и капли. Здесь трёхмерная четверть, и разрыв плёнки получается из уравнений.

## Постановка

| | |
|---|---|
| Область | четверть (90°) вокруг оси форсунки: x −50…250 мм, y и z 0…150 мм |
| Боковые грани | циклические с поворотом на 90°: закрутка газа сохраняется, масло, вышедшее с одной грани, входит через другую |
| Внешние грани | y = 150 и z = 150 мм, гладкие стенки (`slip`); углы квадратные |
| Лансет | ⌀28 мм до x = 82 мм. **Масло выходит из отверстия ⌀20 на его торце, за 1 см до диска**: 24.6 м/с, 32 т/ч на полный круг |
| Диск | ⌀65 × 8 мм, x = 92…100 мм |
| Газ | 55 м/с вдоль оси + закрутка ω = 167 рад/с; ρ 1.106, μ 1.82e-5 |
| Масло | ρ 1150, 40 сСт, σ 0.030 Н/м |
| Турбулентность | в VOF нет (`laminar`); в стационарном старте газа — k-ω SST |

## Сетка
- Фон — кубы 3.2 мм (`system/blockMeshDict`).
- snappyHexMesh вырезает лансет и диск (`make_geometry.py` → `constant/geometry/*.stl`). У диска, торца сопла и в зоне струи он сгущает ячейки до 0.4 мм. Получается 538 тыс. ячеек.
- Дальше сетка **сама** дробится вокруг поверхности масла до 0.4 мм и укрупняется обратно, где масла нет (`constant/dynamicMeshDict`). Предел `maxCells 3000000`.

## Порядок расчёта (`./Allrun`)
1. Сетка: `blockMesh`, `surfaceFeatures`, `snappyHexMesh`, `checkMesh`.
2. **Стационарный газ** в `gasInit/` на той же сетке: `incompressibleFluid`, k-ω SST, 500 итераций.
3. Скорость газа переносится в VOF (`mapFields`) — старт без рывка.
4. Нестационарный VOF до 7 мс (`incompressibleVoF`): первые 0.5 мс только газ, затем масло (`0.orig/alpha.oil`, таблица на `oilInlet`).

**Время у пользователя (8 ядер).** Сетка и газ — минут 15–20. VOF — примерно **8–15 часов**: ~5000 шагов по ~1.3 мкс. Шаг дорожает по мере того, как растёт число ячеек вокруг плёнки.

```bash
cd $FOAM_RUN/CFD-Venturi && git pull
```

```bash
cd nozzle-vof-3d && ./Allrun
```

Картинки — можно и во время расчёта, из второго окна MSYS2:

```bash
cd $FOAM_RUN/CFD-Venturi/nozzle-vof-3d && ./pictures
```

- `frames/f_<время мс>.png` — кадр каждые 0.1 мс; `sheet3d.gif` — анимация из всех кадров; `sheet3d_summary.txt` — по каждому кадру.
- На кадре три вида:
  1. **разрез через ось** — доля масла 0…1;
  2. **«тень» сбоку**;
  3. **«тень» со стороны выхода**.

  Четверть повторена 4 раза по кругу. «Тень» показывает, сколько поверхностей масла пересекает луч зрения: 0 — газ, 2 — одна плёнка, больше — несколько слоёв или капли. **Шкалы фиксированы во всех кадрах.**
- В заголовке кадра и в `sheet3d_summary.txt`: до какого радиуса плёнка цела (одним куском со струёй) и сколько кусков от неё оторвалось.

Остановить с записью: `./stop`. Продолжить: `mpirun -np 8 foamRun -parallel` из папки кейса (стартует с последней полной записи, они каждую 1 мс). Очистить: `./Allclean`.

**В ParaView:** `case.foam`; поверхность масла — фильтр `Contour` по `alpha.oil` = 0.5. Лёгкие поверхности для анимации лежат в `postProcessing/surfaces/<t>/iso.vtk`.

## Что можно менять

| Где | Что |
|---|---|
| `constant/dynamicMeshDict` → `maxRefinement 4` | 0.2 мм у поверхности масла: разрыв точнее, ячеек и времени в разы больше; поднять `maxCells` |
| `make_geometry.py` | размеры лансета и диска. Торцы должны лечь на сетку 0.4 мм от x = −0.0504, иначе адаптивная сетка остановится на проверке циклических граней |
| `0.orig/U`, `gasInlet` | скорость и закрутка газа; то же в `gasInit/0.orig/U` |
| `0.orig/U`, `oilInlet` | скорость масла |
| `system/controlDict` → `endTime` | длительность |

## Ограничения
- 0.4 мм — это 4 ячейки на толщину плёнки у кромки (1.6 мм). Дальше плёнка истончается как 1/r, и примерно с r ≈ 60–80 мм её толщина — 1–2 ячейки. Разрыв там отчасти численный: место и характерный размер нитей правдоподобны, мелкие капли (< 1 мм) не разрешаются.
- Четверть с циклическими гранями повторяет картину каждые 90°. Нити, шаг которых больше четверти окружности, не появятся (на r = 100 мм это 157 мм — нити такие не бывают).
- Газ в VOF без модели турбулентности: крупные вихри считаются, мелкие — нет.

## Почему так (история)
- Сначала был цилиндрический сектор 20°. У оси ячейки получались иглами с соотношением сторон ~300, давление решалось 50–140 итераций за шаг. Перешли на кубы.
- snappyHexMesh сглаживал точки у оси и сдвигал их с плоскостей циклических граней. Адаптивная сетка из-за этого падала: `Faces do not seem to be correct across coupled boundaries`. Помогли две вещи: фон выровнен так, что торцы лежат на линиях сетки, и `nSmoothPatch 0`.
- Балансировка нагрузки между ядрами (`distributor`) в OF-12 падает с `Cannot find a internal patch`, когда циклические грани разрезаны между процессорами. Отключена.
- Перестройка сетки каждый шаг съедала больше половины времени: `refineInterval 3`, `nBufferLayers 2`. Шаг ограничен газом у кромки диска (~140 м/с), поэтому `maxCo 0.9`, `maxAlphaCo 0.5`.
- В OF-12 у `mapFields` нет опции `-fields`. Он переносит все поля газа, лишние (p, k, ω, ν_t) `Allrun` удаляет.
