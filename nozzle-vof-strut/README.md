# nozzle-vof-strut: форсунка на центральной ножке с тремя стойками (3D VOF)

Тот же расчёт, что `nozzle-vof-3d` (струя → диск → плёнка → разрыв), но форсунка ближе к реальной: диск держат **три стойки** (полосы), плюс **центральная ножка ⌀10**. Цель — увидеть, что стойки делают с плёнкой.

## Постановка

| | |
|---|---|
| Область | **полный круг**, x 29.6…160.8 мм, y и z ±121.6 мм. Стенки — `slip`. Вход газа за 5 см до носика |
| Лансет | ⌀28 до x = 82 мм. Масло выходит из **кольца ⌀22.4 / ножка ⌀10** (площадь как у сопла ⌀20), 24.6 м/с |
| Ножка | ⌀10 от лансета до диска, за диском её нет |
| Стойки | 3 полосы 5 × 12 мм под 0°, 120° и 240°, от лансета (x 70 мм, r 16) к кромке диска (x 98, r 32), концы утоплены в лансет и диск. Размеры по фото на глаз — `make_geometry.py` |
| Диск | ⌀65 × 8, x 92…100 мм |
| Газ, масло | как в `nozzle-vof-3d`: 55 м/с + закрутка ω = 167 рад/с; ρ 1150, 40 сСт, σ 0.030 |

## Сетка
- Фон — кубы 3.2 мм.
- snappyHexMesh **без подгонки к поверхности** (`snap off`): стенки ступеньками по 0.4 мм. Все стенки, которых касается масло (лансет, ножка, стойки, диск), измельчены до одного уровня, 0.4 мм. Получается ~685 тыс. ячеек.
- Дальше сетка сама дробится вокруг масла до 0.4 мм, предел `maxCells 3000000`.

## Запуск — так же, как `nozzle-vof-3d`

```bash
cd $FOAM_RUN/CFD-Venturi/nozzle-vof-strut && ./Allrun
```

```bash
./pictures
```

Кадры: **разрез z = 0** — верхняя половина через стойку, нижняя посередине между стойками; «тени» сбоку и со стороны выхода, шкалы фиксированы.

**Время.** У меня на 4 ядрах: 2 мс за ~6 ч. После ~1.7 мс сетка упирается в 3 млн ячеек, и шаг стоит ~8 с. На 8 ядрах до 3–4 мс — ориентировочно 8–12 ч.

## Результат (у меня, до 2–3 мс; масло пущено с 0.1 мс)
- **Плёнка сходит трилистником**: три лепестка между стойками, за каждой стойкой пустой клин ~30–40°.
- **Края лепестков утолщены**: там собираются будущие жгуты.
- На разрезе через стойку масло упирается в стойку и **копится комом у её основания**.
- Между стойками плёнка нормальная: ~82–83° к оси, ~28 м/с, распад с r ≈ 55–60 мм.
- Картинки: `docs/nozzle_strut_sheet.gif`, `docs/nozzle_strut_last.png`.

**Вывод.** Стойки на пути плёнки отнимают у распыла около трети круга и собирают масло в утолщения и комы. Это источник крупных струй, которые бьют в стенку концентрированно. Для сравнения — ножка без стоек: в `make_geometry.py` убрать `strut.stl` и стойки из `snappyHexMeshDict`.

## Грабли (почему так)
- **Полярный сектор 120° с одной стойкой** не пошёл. Адаптивная сетка дробила узкие ячейки у ножки на сотни тысяч лишних (760 тыс. ячеек при масле до r = 23 мм, 4.5 с на шаг). Перешли на полный круг на кубах.
- **Балансировка нагрузки** (`distributor`) в OF-12 падает с `Cannot find a internal patch`, и не только из-за циклических граней. Отключена.
- **Дробление и укрупнение сетки** ломались (`hexRef8 nAnchors:2`, `removeFaces: edge has too few face neighbours`) на ячейках у стоек. Помогли две вещи: убрали подгонку к поверхности и сделали лансет того же уровня, что стойки, — чтобы на стенках рядом с маслом не было перепада уровней сетки.
- `unrefineLevel` в OF-12 нет: отключить укрупнение сетки настройкой нельзя.
